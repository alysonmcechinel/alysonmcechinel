## About me

I'm a .NET developer focused on back-end engineering, building and evolving APIs, integrations, and business logic. I hold a bachelor's degree in Computer Science from UNESC.

I have experience with multi-tenant applications, messaging, asynchronous processing, automated testing, refactoring, and performance optimization. I also work with AI integrations, aiming to build reliable, observable, and maintainable solutions.

This GitHub profile is where I build personal projects, explore engineering approaches, and document my technical growth.
